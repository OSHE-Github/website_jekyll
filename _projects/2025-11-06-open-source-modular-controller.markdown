#### Open Source Modular Controller
The Open Source Modular Controller is a reconfigurable USB game controller with interchangeable button, joystick, navigation, and bumper/trigger modules. Receiver boards can be repositioned within a custom 3D-printed chassis, allowing users to shape the layout around their preferences and accessibility needs. Built around an ESP32-S3 and TinyUSB, the Spring 2026 prototype connects as a standard HID controller without additional drivers.
